### Usage

```sh
image-indexing-engine "home/david/Pictures/girlfriend/"
```

### Output

Under `home/david/Pictures/girlfriend/`:

```sh
.eyeris/
├── thumbnails/             # contains 512px bound thumbnails with name generated by blake3 hash
│   ├── 1dn32hf...rbs.png
│   ├── j5f49hf...asd.png
│   └── ...
└── images.db               # database contain basic info, system metadata and some metadata standards.
```

### Project Structure

```sh
src/
├── main.rs           # CLI
├── lib.rs
├── color.rs          # dominant colors extraction
├── db.rs             # db operations
├── hash.rs           # create unique identity for image using pixels + format
├── index.rs          # indexing pipeline include thumbnailing
├── paths.rs
├── scan.rs           # scan images recursively
└── thumbnail.rs      # resize 512-bound
```

### Database Schema

`images.db` contain single table `images`:

```sql
CREATE TABLE IF NOT EXISTS images (
    hash        TEXT        PRIMARY KEY,            -- 1.  blake3 hash of pixels + format
    path        TEXT        NOT NULL,               -- 2.  rel_path/to/image.png
    name        TEXT        NOT NULL,               -- 3.  image
    format      TEXT        NOT NULL,               -- 4.  PNG, JPG, WEBP
    size        INT         NOT NULL,               -- 5.  in bytes
    width       INT         NOT NULL,               -- 6.  3840
    height      INT         NOT NULL,               -- 7.  2160
    created     INT         NOT NULL,               -- 8.  1792552976580
    modified    INT         NOT NULL,               -- 9.  1792552976580
    rating      INT         DEFAULT 0,              -- 10. 0 to 5
    description TEXT        DEFAULT '',             -- 11. 'A beautiful girl ...'
    tags        TEXT        DEFAULT '[]',           -- 12. ['girl', 'beach', 'sunset']
    palette     TEXT        DEFAULT '[]'            -- 13. List of Oklab (3 floats)
);
```
